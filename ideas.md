# Ideias de Design — Portfólio Pedro de França Moreira

## Abordagem 1 — Terminal Noir
<response>
<text>
**Design Movement:** Cyberpunk/Terminal Aesthetic
**Core Principles:** Interface que imita um terminal de código, tipografia monospace, alto contraste entre fundo escuro e texto neon, sensação de "hacker" sofisticado.
**Color Philosophy:** Fundo preto profundo (#0D0D0D), verde neon (#00FF88) para destaques, branco frio para texto principal. Transmite competência técnica e profundidade.
**Layout Paradigm:** Layout assimétrico com sidebar fixa à esquerda (navegação vertical), conteúdo principal à direita com scroll. Linhas de código decorativas como separadores.
**Signature Elements:** Cursor piscante animado no título, efeito de "digitação" no texto de apresentação, bordas com estilo de terminal ([ ], // comentários).
**Interaction Philosophy:** Hover com efeito de scan line, transições como se o conteúdo estivesse sendo "carregado" no terminal.
**Animation:** Texto sendo digitado na entrada, fade-in linha a linha para seções, cursor piscante constante.
**Typography System:** JetBrains Mono para títulos e destaques, Fira Code para corpo de texto.
</text>

## Abordagem 2 — Brutalismo Técnico
<response>
<text>
**Design Movement:** Neo-Brutalism com influência de documentação técnica
**Core Principles:** Bordas sólidas e espessas, sombras duras sem blur, cores saturadas em blocos, layout de grade rígida com quebras intencionais.
**Color Philosophy:** Fundo creme/off-white (#F5F0E8), azul cobalto (#1A3BCC) para blocos primários, amarelo âmbar (#F5A623) para destaques. Contraste forte, sem gradientes.
**Layout Paradigm:** Grade de 12 colunas com elementos que "quebram" a grade intencionalmente. Cards com bordas pretas de 3px e sombras offset. Sem arredondamentos.
**Signature Elements:** Sombras offset nos cards (4px 4px 0 #000), bordas pretas grossas, numeração de seções em estilo tipográfico grande.
**Interaction Philosophy:** Hover com deslocamento do card (translate), botões com efeito de "pressionar" (sombra reduz ao clicar).
**Animation:** Transições rápidas e mecânicas, sem suavidade excessiva — reflete a precisão técnica.
**Typography System:** Space Grotesk Bold para títulos, IBM Plex Mono para código/destaques, DM Sans para corpo.
</text>

</response>

## Abordagem 3 — Minimalismo Técnico Elegante ✅ ESCOLHIDA
<response>
<text>
**Design Movement:** Swiss/International Style com toque de design de produto moderno
**Core Principles:** Hierarquia tipográfica clara, uso generoso de espaço negativo, paleta restrita e sofisticada, grid assimétrico com âncoras visuais fortes.
**Color Philosophy:** Fundo quase-branco (#F8F9FA), azul petróleo profundo (#0F2D4A) como cor primária, laranja queimado (#E85D26) como acento vibrante. Transmite seriedade técnica com personalidade.
**Layout Paradigm:** Hero de tela cheia com texto alinhado à esquerda e grande, seções alternando entre full-width e coluna central, cards de habilidades em grade irregular.
**Signature Elements:** Linha decorativa fina vertical em laranja ao lado de títulos de seção, número de seção em fonte grande e transparente como elemento de fundo, tags de tecnologia com estilo de badge técnico.
**Interaction Philosophy:** Hover suave com elevação de sombra, underlines animados em links, scroll reveal para seções.
**Animation:** Framer Motion para entrada de elementos (slide-up + fade), hover com scale sutil nos cards, linha de progresso nas skills.
**Typography System:** Sora (display/títulos) + Source Code Pro (código/badges) + Inter (corpo de texto).
</text>

</response>
